# 빼고또 v1.2.0 — 로또 QR 역발상 추천 앱

> **내가 산 자동번호는 싹 빼고, 이번엔 반대로 5게임!**

동행복권 로또 6/45 복권의 QR을 읽고, 구매한 복권에 있는 모든 숫자를 제외해 **새로운 번호 5게임**을 즉시 추천하는 가벼운 모바일 웹앱입니다.

## 화면 흐름

1. **최초 접속:** 콘셉트와 3단계 사용법을 한 화면에 표시합니다. `QR 스캔 시작하기`를 누르면 로컬 저장소에 안내 확인 상태만 기록합니다.
2. **이후 접속:** 안내 없이 즉시 QR 스캔 화면으로 이동하고 카메라 시작을 시도합니다. 브라우저/기기 권한 정책상 자동 실행이 제한되면 `카메라 켜기`를 누릅니다.
3. **QR 인식 성공:** 스캔 화면을 닫고 추천번호 **5게임을 스크롤 없는 결과 화면**에 표시합니다.
4. **내 번호 보기:** 결과 상단의 `내 번호 보기`를 누르면 모달 창에 QR 원본 5게임, 제외 개수, 1~45 번호 현황을 보여줍니다.
5. **처음으로:** 상단 로고 또는 `처음으로`를 누르면 현재 결과를 초기화하고 QR 스캔 화면으로 돌아갑니다. 최초 접속 안내가 다시 나오지는 않습니다.

결과 화면에서 `다시 추천`, `번호 복사`를 사용할 수 있습니다. 복권 사진 선택과 QR 주소 직접 입력도 제공됩니다.

## 모바일 UI

- 화면 높이를 `100dvh`와 safe-area inset으로 처리하고, 소개/QR/결과 화면을 분리합니다.
- 스캔 화면은 남는 공간을 카메라 미리보기에 할당합니다.
- 결과 화면은 5게임과 재추천/복사 버튼이 한 화면에 들어오도록 유동적으로 크기를 조정합니다.
- 화면이 매우 작거나 모바일 키보드가 표시되면 화면 제약이 있을 수 있으며, 원본 번호 모달 내부는 필요시 자체 스크롤을 허용합니다.
- 확대/축소는 핀치와 `+ / −` 및 슬라이더를 지원합니다. 카메라가 지원할 때 하드웨어 줌과 위치 기반 초점을 요청합니다. 미지원 시 디지털 줌과 자동초점으로 대체합니다.

## 추천 규칙

- QR에 담긴 6/45 게임의 번호만 사용하며, 회차·일련번호를 추천 연산에 이용하지 않습니다.
- 사용 가능 숫자: `1~45 − 구매한 게임에 나온 숫자 집합`.
- 남은 숫자에서 각 게임 6개씩 5게임을 생성합니다. 게임 내부에는 중복이 없고, 게임 간에는 사용 횟수가 적은 숫자를 우선하여 고르게 분배합니다.
- 남은 숫자가 6개 미만이면 생성할 수 없습니다.
- 기존 번호 제외는 사용자가 지정한 조합 방식일 뿐 **로또 당첨 확률을 높이지 않습니다.**

## 환경과 개인정보

- 구성: `index.html` 단일 파일 (CSS/JavaScript 내장). 별도 서버, 가입 또는 데이터베이스 불필요.
- QR 읽기: `BarcodeDetector`가 지원되면 우선 사용하고, 지원되지 않으면 CDN의 `jsQR 1.4.0`으로 분석합니다.
- **사진/원본 QR/개별 게임 정보는 서버로 전송하거나 저장하지 않습니다.** 최초 안내 확인 여부(`ppaego-intro-v1=seen`)만 브라우저의 `localStorage`에 저장합니다.
- 일부 브라우저에서는 외부 `jsQR` 파일 로드를 위해 최초 실행 시 인터넷 연결이 필요합니다.
- 카메라 권한은 HTTPS 또는 localhost에서 사용할 수 있습니다. 자동 카메라 시작 성공 여부는 운영체제/브라우저의 카메라 권한 정책에 따라 다릅니다.

## 배포 (GitHub Pages)

`index.html`과 `README.md`를 저장소 루트에 올리고 `Settings → Pages → Deploy from a branch`에서 해당 브랜치의 루트(`/(root)`)를 선택하면 됩니다.
