# 빼고또 🍀
### Reverse Lotto Pick & Daily Fortune

**내가 산 자동번호는 싹 빼거나, 오늘의 기운을 가득 담아 5게임!**

로또 용지의 QR을 스캔하여 **이미 구매한 번호를 모두 제외하고** 남은 숫자로 새 번호를 만드는 역발상 추천과, 복권이 없어도 **오늘 날짜의 맑은 행운 에너지를 담아 즉시 뽑아보는 오늘의 추천번호**를 제공하는 모바일 웹앱입니다.

## 💡 시작 메뉴 2가지

사람이 정성스레 만든 친근한 대시보드에서 원하는 방식으로 5게임을 시작할 수 있습니다:

### 1. `QR 스캔 시작하기 →` (로또 QR로 빼고또)
> “자동으로 산 번호가 영 마음에 안 드는데, 차라리 **그 번호들을 전부 빼고** 다시 뽑아 보면 어떨까?”

- 구매한 로또 6/45 복권의 QR을 비추면 번호를 즉시 추출합니다.
- 기존 게임에 등장한 모든 숫자를 싹 제외(`Set` 연산)합니다.
- 제외되지 않고 남은 후보 숫자들로 **중복 없이 알찬 새로운 5게임**을 조합합니다.

### 2. `오늘의 추천번호 →` (오늘의 기운을 담아서)
> “복권 용지가 없어도, 오늘 날짜의 좋은 기운을 담아 가볍게 번호를 받아보고 싶을 때!”

- 당일 날짜(월/일/요일)의 긍정적인 행운 메시지와 함께 1부터 45까지 기운 좋은 숫자를 조율합니다.
- 5게임(총 30개 번호 슬롯) 전체에서 숫자가 쏠리지 않고 고르게 퍼지도록 정성껏 조합합니다.
- 언제든 원클릭으로 가볍게 오늘의 설렘을 확인하고 번호를 복사할 수 있습니다.

## ✨ 주요 기능

| 기능 | 설명 |
| :-- | :-- |
| **따뜻한 홈 대시보드** | 요일별 행운 한마디, 날짜 뱃지, 부드러운 터치 카드가 적용된 앱 스타일 UI |
| **오늘의 추천번호** | 복권 없이도 오늘 날짜의 맑은 기운을 담아 5게임을 한 번에 생성 |
| **QR 자동 인식** | 로또 6/45 QR에서 회차와 게임별 번호를 즉시 해독 (별도 OCR 불필요) |
| **다양한 스캔 지원** | 실시간 카메라(핀치 줌, 배율 조절, 터치 초점), 사진 앨범, URL 직접 입력 |
| **기존 번호 완벽 제외** | 구매한 복권에 나온 숫자는 새로운 추천 세트에 단 1개도 들어가지 않음 |
| **큰 로또볼 UI** | 모바일 한 화면(`100dvh`)에 5게임이 한눈에 쏙 들어오는 큰 글씨 로또볼 디자인 |
| **결과 복사 & 팝업** | 추천 번호를 깔끔하게 클립보드에 복사하고, 내 구매 번호와 1~45 현황 확인 가능 |
| **PWA 홈 화면 추가** | 스마트폰 홈 화면에 바로가기 앱 아이콘 추가 지원 (`manifest.webmanifest`) |

## 🔢 추천 알고리즘

- 브라우저 내장 암호학적 난수 생성기(`crypto.getRandomValues`)를 사용하여 편향 없는 무작위성을 확보합니다.
- **QR 제외 모드:** 구매 번호(보통 18~25개)를 제외한 남은 후보군(20~27개)에서 5게임을 구성하며, 5게임 전체에 걸쳐 후보 숫자들의 출현 횟수가 균등해지도록 빈도 카운팅 정렬을 수행합니다.
- **오늘의 추천 모드:** 1~45 전체 번호 풀에서 5게임(30개 번호)을 생성하며, 5게임 안에서 번호들이 겹치지 않고 다채로운 30개 숫자가 고르게 배정됩니다.

> [!NOTE]
> 번호를 제외하거나 오늘의 기운으로 뽑는다고 해서 개별 로또 조합의 수학적 당첨 확률이 변하지는 않습니다. 소소한 일상의 즐거움과 설렘을 위한 도구이며, 동행복권 공식 서비스가 아닙니다.

## 🛠 기술 스택

- **프런트엔드**: HTML5, CSS3, Vanilla JavaScript (외부 프레임워크 없는 초경량 단일 파일 구성)
- **QR 엔진**: 브라우저 네이티브 `BarcodeDetector` 우선 활용 + 하위 호환용 `jsQR 1.4.0` CDN
- **도메인 & 호스팅**: [https://picklotte.vercel.app/](https://picklotte.vercel.app/) / Vercel & GitHub Pages
- **개인정보 보호**: 모든 QR 해석과 번호 생성은 사용자의 기기 브라우저 내부에서만 처리되며, 어떠한 서버로도 전송되지 않습니다.
