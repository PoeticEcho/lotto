# 빼고또 🍀
### Reverse Lotto Pick

**내가 산 자동번호는 싹 빼고, 이번엔 반대로 5게임!**

로또 용지의 QR을 스캔하면, **이미 구매한 번호를 모두 제외하고** 남은 숫자로 새로운 5게임을 만들어 주는 역발상 로또 번호 추천 웹앱입니다.

## 💡 왜 만들었나요?

> “자동으로 산 번호가 영 마음에 안 드는데, 차라리 **그 번호들을 전부 빼고** 다시 뽑아 보면 어떨까?”

일반적인 로또 추천 앱은 번호를 **선택**합니다. 빼고또는 반대로, **기존에 구매한 복권의 번호를 제거하는 것부터 시작**합니다.

복권의 QR에는 게임별 선택번호가 포함되어 있으므로 숫자를 OCR로 읽을 필요도 없습니다. **QR 한 번이면 원본 번호 확인부터 새 조합 추천까지 끝**납니다.

## 📱 사용 방법

| 단계 | 화면 | 동작 |
| :--: | :-- | :-- |
| **01** | 처음 방문 안내 | 앱의 컨셉과 사용법을 **최초 한 번만** 보여 줍니다. |
| **02** | QR 스캔 | 카메라로 복권의 QR을 비추거나 사진/QR 주소를 입력합니다. |
| **03** | 추천 연출 | QR 확인 → 기존 번호 제외 → 새 조합 준비 과정을 짧게 보여 줍니다. |
| **04** | 결과 | 제외한 번호를 사용하지 않은 **새로운 5게임**을 크게 표시합니다. |

- 두 번째 방문부터는 안내 화면을 건너뛰고 **스캔 화면**으로 진입합니다.
- QR 인식 성공 후 **별도 추천 버튼 없이** 결과 화면으로 이동합니다.
- **내 번호 보기**를 누르면 원본 게임 번호와 제외 현황이 팝업으로 열립니다.
- **다시 추천**으로 같은 제외 조건에서 새로운 조합을 만들 수 있습니다.
- **번호 복사**로 추천한 5게임을 복사할 수 있습니다.
- 상단 **빼고또 로고** 또는 **처음으로**를 누르면 스캔 화면으로 돌아갑니다.

## ✨ 주요 기능

| 기능 | 설명 |
| :-- | :-- |
| **QR 자동 인식** | 로또 6/45 QR에서 회차와 게임별 번호를 읽습니다. |
| **OCR 불필요** | 복권에 인쇄된 번호를 사진 문자 인식하지 않습니다. |
| **다양한 입력** | 실시간 카메라, 저장된 사진, QR 주소 직접 입력 |
| **카메라 조작** | 핀치 줌, 확대·축소 버튼, 배율 슬라이더, 터치 초점 요청 |
| **번호 자동 제외** | 기존 게임에서 한 번이라도 나온 번호는 모두 제외 |
| **5세트 추천** | 남은 번호에서 6개씩 조합, 각 게임 내부 중복 방지 |
| **큰 로또볼 UI** | 모바일에서도 읽기 쉽도록 큰 숫자와 색상 적용 |
| **짧은 추천 연출** | 약 1.85초 동안 단계별 안내 후 결과 공개 |
| **스크롤 최소화** | 주요 모바일 화면에서 5게임을 한 화면에 표시하도록 설계 |
| **원본 번호 팝업** | 원본 5게임 및 1~45 번호의 제외 여부 확인 |
| **홈 화면 추가** | 앱 매니페스트와 전용 아이콘 제공 |

**참고:** 터치 초점 및 하드웨어 줌은 모바일 브라우저와 기기의 지원 여부에 따라 달라집니다. 초점 미지원 환경에서는 자동초점을 사용하며, 확대 기능은 디지털 방식으로 동작할 수 있습니다. 카메라 권한이 필요합니다.

## 🔢 번호 추천 방식

1. QR에서 유효한 로또 6/45 게임을 추출합니다.
2. 구매한 게임의 번호를 하나의 집합으로 합쳐 **중복 번호를 한 번만** 제외합니다.
3. **1~45 중 제외되지 않은 숫자**를 후보로 남깁니다.
4. 남은 후보에서 **6개씩 5세트**를 구성합니다.
5. 한 게임 내 번호는 중복 없이 정렬하고, **5게임 전체에서는 후보 숫자의 사용 횟수를 가능한 한 고르게 분배**합니다.

예를 들어 구매한 5게임에서 서로 다른 숫자 22개가 등장했다면:

| 구분 | 개수 |
| :-- | --: |
| 전체 로또 번호 | 45개 |
| 기존 구매 번호(중복 제거) | 22개 |
| 새 추천에 사용할 수 있는 번호 | **23개** |
| 생성하는 새 조합 | **5게임 × 6개 = 30개 자리** |

남은 후보가 23개이므로 서로 다른 30개 숫자를 만들 수는 없습니다. **게임 간에는 숫자가 반복될 수 있지만, 각 게임 안에서는 중복되지 않습니다.** 남은 숫자가 6개 미만이면 생성하지 않고 안내 메시지를 표시합니다.

> [!IMPORTANT]
> 기존 번호를 제외한다고 해서 로또의 **개별 조합 당첨 확률이 올라가지는 않습니다.** 이 앱은 새로운 방식으로 번호를 구성해 보는 재미를 위한 도구입니다. 동행복권 공식 서비스가 아닙니다.

## 🛠 기술 구성

**별도 백엔드, 데이터베이스, 회원가입 없이 실행되는 정적 웹앱**입니다.

| 구분 | 기술 |
| :-- | :-- |
| 프런트엔드 | HTML5 · CSS3 · Vanilla JavaScript |
| QR 해석 | 브라우저 `BarcodeDetector` 우선, 미지원 환경은 `jsQR 1.4.0` |
| 카메라 | `getUserMedia` · MediaStreamTrack 제약 기능(지원 시) |
| 번호 생성 | 브라우저 `crypto.getRandomValues` 사용 가능 시 우선 |
| 최초 방문 기록 | `localStorage` |
| 호스팅 | GitHub Pages |
| 배포 | GitHub Actions |
| 브랜딩 | SVG favicon · OG 이미지 · 앱 아이콘 · Web App Manifest |

QR 파서는 동행복권 도메인의 QR URL 및 지원하는 번호 데이터 형식을 검증합니다. 다른 형식의 복권, 손상된 QR, 브라우저별 카메라 제약은 지원되지 않을 수 있습니다.

### 개인정보

- QR 이미지는 **사용자의 브라우저에서 분석**하며 별도 앱 서버에 업로드하지 않습니다.
- 복권에 있는 번호·일련번호를 자체 서버나 데이터베이스에 저장하지 않습니다.
- 브라우저 로컬 저장소에는 **최초 안내를 봤는지** 여부만 기록합니다.
- 일부 브라우저에서는 QR 해석 라이브러리를 CDN에서 받아 오므로 **인터넷 연결이 필요할 수 있습니다.**
- 로또 결과의 공개 배포나 추적, 복권 구매 대행 기능은 제공하지 않습니다.

## ▶️ 개발 및 배포

**로컬 실행:** 저장소를 내려받고 루트 폴더에서 로컬 웹서버를 실행하세요.

~~~bash
git clone https://github.com/PoeticEcho/lotto.git
cd lotto
python -m http.server 8000
~~~

브라우저에서 `http://localhost:8000`을 엽니다. 카메라는 HTTPS 또는 localhost 등 보안 컨텍스트에서만 사용할 수 있습니다. QR 라이브러리 CDN을 사용하는 브라우저는 인터넷 연결이 필요할 수 있습니다.

**배포:** GitHub Pages는 이미 `GitHub Actions` 소스로 설정되어 있습니다. `main` 브랜치에 변경사항을 푸시하면 [배포 워크플로](https://github.com/PoeticEcho/lotto/actions/workflows/pages.yml)가 자동 실행됩니다.
