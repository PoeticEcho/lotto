# 빼고또 🍀 — Reverse Lotto Pick

> **내가 산 자동번호는 싹 빼고, 이번엔 반대로 5게임!**

로또 6/45 복권의 **QR코드를 읽고, 그 복권에 등장한 모든 숫자를 제외한 다음 남은 숫자로 5세트**를 추천하는 무료 모바일 웹앱입니다.

**앱 주소:** https://poeticecho.github.io/lotto/

## 사용법
1. **첫 접속에만** 앱 컨셉과 사용법을 안내합니다.
2. 다음 접속부터는 QR 스캔 화면으로 바로 이동합니다. 카메라 권한이 허용되면 자동 실행을 시도합니다.
3. 복권 QR 인식 → 약 **1.85초의 화면 연출**(QR 확인, 기존 번호 제외, 새 조합 준비) → **새 번호 5게임**이 한 화면에 표시됩니다. 실제 계산을 기다리는 시간은 아닙니다.
4. **내 번호 보기**를 선택하면 구매한 게임 번호와 제외 목록을 팝업으로 확인합니다.
5. 결과 화면에서 **다시 추천**, **번호 복사**가 가능하며, 상단 로고 또는 **처음으로**를 누르면 QR 스캔으로 돌아갑니다.

복권 QR **사진 업로드**, **QR 주소 직접 입력**도 지원합니다.

## 모바일 UI 및 카메라
- 5개 게임이 기본 모바일 화면에서 스크롤 없이 표시되도록 설계했습니다.
- 로또볼 약 **39~50px**, 굵고 선명한 숫자, 번호대별 색상.
- **두 손가락 핀치 줌**, 배율 슬라이더, `+ / −` 버튼.
- **터치 위치 초점 요청**(기기·브라우저가 지원할 경우). 미지원 시 자동 초점 유지.
- 화면 로딩 중 처음으로 이동하면 뒤늦게 결과 화면이 나타나지 않도록 타이머를 취소합니다.
- 모션 줄이기 운영체제 설정을 사용할 경우 화면 연출을 짧게 제공합니다.

## QR 및 추천 규칙
- QR 번호 파싱: `1~45` 숫자 범위와 각 게임의 중복 여부 검증.
- 제외 대상: **구매한 모든 게임에 한 번 이상 등장한 숫자 집합**.
- 추천 대상: **1~45 중 제외되지 않은 번호**.
- 5게임 × 6개 번호를 생성하며, 한 게임 안에 중복은 없습니다.
- 게임 간에는 숫자 사용 횟수를 가능한 한 고르게 분산합니다.
- 남은 번호가 6개보다 적으면 추천 불가 메시지를 표시합니다.

**참고:** 기존 번호를 제외해도 로또 당첨 확률이 높아지는 것은 아닙니다. 조합을 만드는 재미를 위한 앱입니다.

## 개인정보 및 실행 환경
- 가입·서버 DB 불필요. 사용자 사진과 QR 번호는 기기에서 분석하고 서버에 업로드하지 않습니다.
- 첫 방문 안내 확인 여부만 브라우저 `localStorage`에 기록합니다.
- QR 해독: `BarcodeDetector` 우선, 미지원 브라우저는 jsQR 1.4.0(CDN)으로 대체.
- 카메라 사용에 HTTPS와 카메라 접근 권한이 필요합니다.

## 브랜딩 에셋
- `favicon.svg`: 남색 바탕의 흰색 마이너스 로고.
- `og.svg`: 1200×630 공유용 OG 디자인 소스. 실제 복권 QR/일련번호는 포함하지 않은 예시 디자인입니다.
- `manifest.webmanifest`: 홈 화면 추가용 앱 설정.
- 배포 워크플로가 SVG를 PNG로 변환하여 `og.png`, `favicon.png`, `icon-192.png`, `icon-512.png`을 게시합니다.

## GitHub Pages 배포
> **첫 배포는 저장소 소유자 설정이 한 번 필요합니다.**
>
> 1. [Repository Settings → Pages](https://github.com/PoeticEcho/lotto/settings/pages)로 이동합니다.
> 2. **Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
> 3. [Actions → Deploy 빼고또 to GitHub Pages](https://github.com/PoeticEcho/lotto/actions/workflows/pages.yml)에서 **Run workflow**를 실행합니다. 이후에는 `main`에 푸시하면 자동 배포됩니다.
>
> 기존 GitHub 연결 앱에는 새 Pages 사이트를 만드는 관리 권한이 없으므로 위 1회 설정이 필요합니다.

배포 후 확인: [앱](https://poeticecho.github.io/lotto/) · [OG 이미지](https://poeticecho.github.io/lotto/og.png) · [favicon](https://poeticecho.github.io/lotto/favicon.svg)
